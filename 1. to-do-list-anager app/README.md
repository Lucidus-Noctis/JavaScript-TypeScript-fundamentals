# Task Manager

## Application Purpose
A simple task management application built with JavaScript and Node.js. It allows users to organize tasks, track their completion status, and manage priorities and deadlines.

## Implemented Features
- Add and remove tasks.
- Mark tasks as completed.
- Search tasks by title (case-insensitive).
- Sort tasks by name and priority.
- Track task statistics, including completion rate.
- Export and import tasks using JSON.
- Validate imported data and handle invalid JSON.

## Challenges Encountered
- Managing tasks efficiently using `Map`.
- Implementing sorting with custom comparison functions.
- Handling invalid JSON and validating imported data.
- Maintaining unique task IDs after importing data.

## Lessons Learned
- How to use JavaScript classes, private fields, and methods.
- How to work with `Map`, arrays, and array methods.
- How to handle errors using `try...catch`.
- How to serialize and deserialize data with JSON.
- The importance of input validation and separating responsibilities in code.
